# bible/ — the invented world (the show's canon)

This is what the show must stay consistent with. "Canon" on this project means *this folder*, not history. Continuity is the discipline: the fiction must agree with itself.

## Layout

- `premise.md` — the top-level frame. **Open until chosen.** Gates everything else.
- `world/` — setting, era, institutions, the store itself, rules of the fictional place.
- `characters/` — the ensemble. Each character is invented; note real-world inspirations informally if useful, but there is no register-tagging system.
- `timeline.md` — the world's internal chronology (added once a premise exists).

## Rules

- Nothing here assumes a setting until `premise.md` is filled.
- If a scene needs a fact the bible doesn't have, add the fact here deliberately — don't smuggle it into the script.
- If the bible ever contradicts itself, fix the newer claim or revise the older one on purpose and note why. The `continuity-lint` tool (in the **gstack** repo) helps catch drift.
