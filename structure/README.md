# structure/ — Structure Lab exports

Structure is developed, not chosen by taste. Competing structural approaches are run through **Structure Lab** as ingredient sets, written here as candidates, and one is locked.

## Files

- `candidates.md` — competing structural approaches with stable ids. **Not seeded yet:** candidates are premise-dependent, and the premise is open (`bible/premise.md`). Written once a Structure Lab session exists.
- `selected.md` — the locked choice. A human decision, not a tool output. **Do not write beats until this exists.**

## TV-structure lens (applies once candidates exist)

Series-native concerns the Lab weighs: A/B/C-story braiding, cold-open discipline, the series engine vs. the season arc, procedural-with-a-spine.
