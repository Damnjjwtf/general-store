# IP Runner (staging)

**An opinionated operating system that runs a piece of IP from spark → bible → script → deck → visual identity, with memory and consistency as first-class citizens.**

The tools are commodities. The product is the **method** — the discipline that turns a spark into a produceable, self-consistent IP and never loses the thread.

`general-store` is the first *project* running on IP Runner. IP Runner is the **engine**. Right now they're fused in this repo; these docs are the extraction-ready staging area for the engine.
